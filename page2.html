Apresentação das interfaces do projeto

Interface 1: Consulta dos dados registrados.

O sistema possuí consulta dos dados registrados de forma facilitada e dinâmica, onde é possível organizar documentos por ano, mês ou outro critério.

Aba de Consulta dos Dados Registrados.

Utilização de documento externo do Excel para registro de dados,
sendo possíveis multiplas pastas, com tabelas criadas automaticamente.

Interface 2: Registro dos dados de modo estruturados - dividido em várias abas para cada etapa do processo

O sistema de registro possuí várias abas para registrar dados de produção, onde as 7 ferramentas da qualidade "saltam na tela".

Análise de dados em tempo real. Interação ao clique (drill-down).

As 7 Ferramentas surgem ao longo do registro dos dados.

Gráficos "Mini e Grande" para visualização de dados.

Aba de Registro.

Carta de Controle (Limites Fixos e CEP).

Análise Multifatorial RSM.

Interface 3: Utilidades incluem: Andon, Templates, Calendário, Metodologias e outros vários recursos sobre a qualidade

O A interface possuí vários recursos adicionais para análise e tomada de decisão.

Andon onde é possivel verificar status do processo e info de itens produzidos.

Templates de ferramentas e metodologias de qualidade para aplicações de melhorias.

Vários Templates de ferramentas e metodologias de qualidade.

Calendário de atividades e prazos de registros de melhorias.

Linha do tempo didática de eventos importante para Qualidade.

Um mini curso de introdução à qualidade.

Interface 4: Aqui acontece a análise dos dados históricos.

Lista de Verificação, Histograma, Cartas de Controles, Diagrama de Dispersão, Diagrama de Pareto, Fluxograma e Diagrama de Ishikawa.

A Lista de Verificação define as variáveis de interesse para registro e análise.

Criação e visualização de Fluxogramas com metadados em cada elemento do fluxo.

Diagrama de Ishikawa integrando "váriaveis" da Lista de Verificação.

Pareto.
